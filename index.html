Parsing assumptions
  • Each selected file produces exactly one CSV row. Columns are the union of fields found across all files.
  • Visible table labels, parameter rows, report metadata, and text lines in Name: value form are collected.
  • Nested headings and table captions prefix fields with an underscore path (for example Power_Actual).
  • Confidence-test measurement tables export only Actual Reading; category, parameter, and unit are combined (for example 2MHz_ReceiverTemperature (C)).
  • DDSR parameter tables export only Test Meas.*; colon-separated results such as FRAM Test: PASS are retained.
  • Nested ECMB diagnostics tables use the outer Actual Reading header; blank colon-separated metadata labels remain available as empty columns.
  • Nested M5 diagnostics tables tolerate blank units and retain Actual Reading status suffixes such as H, L, and NaN Failed.
  • AGR/DDS2 matrices are flattened by section, row, and measurement header; Burst Header channels stay together.
  • Repeated fields are retained in source order and joined with | ; blank values do not overwrite a populated value.
  • Files are read locally in your browser and are never uploaded.
  • Tables with 3 or more columns that don't match a known limits-style or labeled-header layout trigger a review step: pick "Flatten all columns," select specific column(s), or skip that table, per unique table layout. If a verified template CSV is loaded, this review is skipped entirely — the template's own columns decide which parts of these tables to keep.
  • Downloading suggests a file name in the form yymmdd-hhmmss-key-productname-flattenCT.csv, where the 8-digit key and product name (e.g. EWR-P4, EWR-SOLAR, EWR-SP4, EWR-M5, AGR, ECMB, HCIM, PWD, PCG, PCM, DDSR-HCIM, XBAT) are read from the uploaded file name(s). If either is missing, a placeholder is shown so you can fill it in before downloading.
